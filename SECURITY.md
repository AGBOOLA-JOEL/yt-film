# Security

If you find a security problem (code that runs something it shouldn't, a way the engine or setup scripts could leak
your keys, or a credential committed to this repository), **don't open a public issue**. Report it privately:
open the repository's **Security** tab → **Report a vulnerability** (GitHub private vulnerability reporting).

Please include what you found, how to reproduce it, and what it could affect. You'll get a reply as soon as the
maintainer can look at it.

Keeping your own setup safe:
- Your API keys live only in `.env` files, which are ignored by git. Never paste them into issues.
- Download images, voices and music only from sources you trust.
